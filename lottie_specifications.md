# Lottie Specifications

> Drop JSON files into `assets/lottie/`. Wire via `Lottie.asset('assets/lottie/<file>.json')`.

| File | Duration | FPS | Loop | Layers | Easing | Trigger |
|------|----------|-----|------|--------|--------|---------|
| confetti.json | 4s | 30 | one-shot | particles + burst | ease-out | Payment success / level up |
| loading_spinner.json | 1.2s | 60 | loop | rotating ring + pulse | linear | Loading states |
| success_check.json | 0.8s | 60 | one-shot | check draw-on | ease-out-back | Task complete |
| gem_float.json | 2s | 30 | loop | floating gem | ease-in-out | Gem store idle |

Color palette: #00E5FF (cyan), #2979FF (blue), #7C4DFF (purple), #FFD700 (gold).
