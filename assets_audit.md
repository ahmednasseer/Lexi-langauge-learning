# Assets Audit — Lexi (lingua_ai)

> Generated by static source audit. No asset generation performed (environment cannot produce binary art/audio/fonts). All findings verified from source.

## Summary

The Flutter app is **asset-light**: it renders all UI using Flutter `Icons.*` (Material icon constants) and `google_fonts` (Poppins, fetched at runtime via the `google_fonts` package). There are **no** `Image.asset`, `AssetImage`, `SvgPicture.asset`, `Lottie.asset`, `rootBundle.load`, or bundled-font usages anywhere in `lib/`.

Therefore there are **no broken asset references** in code. The only asset-like string in source is a mock value (`goethe_exam_service.dart:169` → `audio/listening/{level}_$i.mp3`) that is stored in a model field but never loaded by any asset API and never points at an existing file.
